# Netflix Data Analysis — Exploratory Data Analysis

## Project Overview

This project performs exploratory data analysis on a Netflix Movies and TV Shows dataset.

The goal is to understand the structure of the catalog and identify patterns related to content types, ratings, genres, countries, release years, movie durations, and other characteristics.

## Objectives

- Examine and understand the dataset
- Clean and preprocess the data
- Handle missing and inconsistent values
- Analyze Movies and TV Shows
- Explore ratings, genres, and countries
- Analyze release-year trends
- Analyze movie durations
- Investigate when titles were added to Netflix
- Identify meaningful patterns through visualization

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis

The project follows a question-driven EDA approach:

**Question → Analysis → Visualization → Observation → Insight**

The analysis includes:

- Movies vs TV Shows
- Content ratings
- Genres
- Countries
- Release-year trends
- Movie durations
- Content trends over time
- Ratings by content type
- Country distribution by content type
- Release periods
- Age of titles when added
- Directors and actors
- Genres by content type

## Key Findings

The analysis found that Movies make up approximately 69.62% of the dataset, TV-MA is the most common rating, International Movies is the most common genre, and the United States is associated with the highest number of titles among the countries analyzed.

The analysis also found that 2018 had the highest number of titles among the release years analyzed, while most movies were between 90 and 119 minutes long.

## Limitations

The dataset represents a historical catalog snapshot and contains missing information in several fields. Country and genre values can contain multiple entries for a single title, and release year should not be confused with the date a title was added to Netflix.

## Conclusion

This project demonstrates the use of Python-based data cleaning, exploratory analysis, and visualization to investigate a real-world dataset and extract evidence-based insights.
